# Houg of Queens

Ein 3D-Browserspiel als **nicht-kommerzielles Fanprojekt** (inspiriert von einer Sitcom über einen Paketfahrer in Queens). Läuft komplett im Browser (three.js), keine Installation.

- `index.html` – Spiel für PC (Tastatur/Maus/Controller)
- `index-mobile.html` – Variante für Smartphones mit Touch-Steuerung (iOS/Android, Querformat)
- `src/` – Quellcode (`head.html`, `js/*.js`, `build.sh`)
- `models/` – Figuren als GLB (in die HTML-Dateien eingebettet)
- `audio/` – Sound- und Sprachdateien (fehlen sie, springt die Browser-Sprachausgabe ein)

## Starten
Als statische Seite über **HTTPS** hosten (z. B. GitHub Pages, Coolify, Netlify). Lokal reicht ein Doppelklick auf `index.html`; three.js und Schriften werden per Internet geladen.

## Hinweis
Fanprojekt ohne Verbindung zu den Rechteinhabern der Serie. Figuren, Namen und Anspielungen gehören ihren jeweiligen Inhabern.
